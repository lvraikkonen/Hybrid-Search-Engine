# 21v-DEV 知识工作台 · 功能演示

面向开发组会议的静态交互 Demo。展示从授权问答、资料上传到差异审核、发布、回退的完整旅程。界面采用 Apple 风格的排版、留白、层次与轻量反馈，不需要安装前端依赖。

## 打开

直接用现代 Chrome、Edge 或 Safari 打开本目录的 `index.html`。所有页面资源和两份样例都在本目录中，无需外网或模型密钥。若浏览器限制本地文件或本地保存，使用本机预览：

```sh
# 在仓库根目录运行
python3 -m http.server 8765 --bind 127.0.0.1 --directory functional-demo
```

然后访问 <http://127.0.0.1:8765/>。终端按 Ctrl+C 结束预览。浏览器进度保存在当前来源的 localStorage；不同浏览器、端口和本地文件模式不共享进度。左下角“重置演示进度”可以重新开始。

侧栏默认收起为图标栏，鼠标移入展开、移出收起；也可使用左上角按钮展开，再点图钉固定。固定偏好会保留到下次打开。当前用户的会话在侧栏下部逐条列出，点击即可继续。窄屏使用展开按钮打开侧栏。

聊天首页在当前窗口内完整呈现；提交问题后，回答以本地模拟的流式效果逐段显示，可以随时“停止生成”。长对话在消息区滚动，输入框保持可见；向上阅读时不会被新文字强制拉回底部。引用和反馈操作在生成结束后显示。

个人记忆默认开启，在聊天后台保存当前用户明确表达的称呼、工作背景、常用区域和回答偏好，供后续会话使用；不会新增通知、逐条审核或常驻面板。右上角个人菜单 → **个人记忆** 可查看、暂停、逐条删除或清空。重新表述同类信息会替换原值；暂停后停止新增和使用，删除后不会从旧聊天自动恢复，已有聊天消息仍保留。也可以直接说“清空我的个人记忆”。

记忆演示：Laojiu 说“我主要负责 MySQL 运维，我常用中国北部 3，以后回答简洁一点。”，新建会话后问“MySQL B1MS 按 730 小时每月多少钱？”，回答会采用常用区域和简洁格式，同时保留价格单位、估算条件及引用版本。再问“我负责什么？”，可看到此前提供的背景。切换 Daozi 或 21v-admin，不能在自己的记忆入口或回答中读取 Laojiu 的记忆。

记忆与知识库分开：不会从资料或历史答案提取报价、政策摘录、文档指令作为记忆，也不改变组权限；每次知识问答仍检索当前已授权、已发布的资料。纯个人记忆回答不进入共享反馈，记忆内容不写入共享活动和费用明细。此版只用保守规则识别上述四类自然表达，不是通用语义记忆，也不回填旧会话。

**隔离边界：** 静态 Demo 按用户分别保存并使用记忆，但演示切换器和 localStorage 位于同一浏览器，不能作为真正的隐私或安全边界，请仅使用演示信息。正式后端必须从认证会话获取用户身份，以组织与用户共同限定记忆的读、写、删除、检索及缓存；不能接受聊天文本或客户端指定的所有者，管理员也不能代读内容。记忆上下文不能进入共享知识索引、提示词缓存、反馈或日志；暂停、删除后须同步失效相关上下文。这些服务端保障尚未实现。

## 演示身份

右上角可随时切换身份，不会清空演示进度。

| 身份 | 用户组 / 职责 | 默认知识范围 |
| --- | --- | --- |
| Laoyang、ZZQ | 21v-Playbook · 普通用户 | Playbook 操作手册 + 各自个人知识 |
| Laojiu、Daozi | 21v-ACN · 普通用户 | ACN 产品价格 + 各自个人知识 |

本次演示固定为 21v-DEV 部门，用户与组预置。21v-Zhuanjiazu 等跨部门推广，以及不同客户的组织隔离属于后续版本。

## 建议演示顺序（10–15 分钟）

页面左下角“会议演示导览”也提供可点击的步骤入口。

1. **从真实资料问答开始。** Laoyang 点击“Azure 预留交换策略有什么变化？”。打开引用，查看文档 v1、知识库 R1、原文片段和全文。
2. **展示权限边界。** Laoyang 问“中国北部 3 的 MySQL B1MS 每小时多少钱？”，当前范围没有可用资料。切换 Laojiu 问同一问题，原始样例价格是 ¥0.1449/小时。切换 Daozi 可看到相同项目范围，但会话各自独立。
3. **展示个人知识。** Laoyang 点击输入框旁的加号，默认目标为个人知识。上传或粘贴 `会议笔记.md`，例如 `# 会议笔记\n\n周五下午进行试运行，由 Laoyang 收集反馈。`（粘贴时将 `\n` 换成实际换行）。提交并确认发布，再问“会议笔记中的试运行如何安排？”。切换 ZZQ，其个人空间不包含这份资料。
4. **观察未发布版本。** Laoyang 进入“知识库 → Playbook 操作手册 → 查看 → 创建演示修订”。演示新增第 16 节内部执行清单。查看“可读对比”和“原始差异”，原文 Git diff 精确保留变更。在确认发布之前，问“提交预留交换申请前需要哪些检查？”，不会得到待审内容。
5. **审核与冲突处理。** 可点击“创建并行修订”，构造不同审核负责人的候选版本。切换 21v-admin → 审核与发布 → 查看差异，核对候选；有冲突时先选择保留版本，再确认发布。也可以先“模拟索引失败”，观察 R1 仍生效，再“重试并发布”。
6. **新答案与旧依据。** 切回 Laoyang 再问检查清单，回答引用新文档版本和 R2，明确标注“演示修订”。以前的会话仍保留回答时的引用版本。回答下方可以提交反馈，管理员在“反馈”页查看、标记评估候选或已处理。
7. **回退与撤回。** 管理员进入文档“版本与发布”，对原始 v1 点击“恢复此内容”。系统生成新文档版本与新知识库发布记录，不删除历史；后续问答恢复原始内容。撤回文档则使后续问答不再检索它，也可从历史版本恢复。
8. **补充管理能力。** “用户与权限”调整跨组查询 / 上传授权；撤销后历史回答中的相关内容也会隐藏。“模型管理”保存配置、模拟连接、启停问答；“RAG 实验室”按阶段配置、对照评测、人工审核与回退；“用量与费用”调整预算、查看和导出演示用量。

可选的价格更新演示：Laojiu 创建 MySQL 修订，将中国北部 3 的 B1MS 从 0.1449 改为 **0.1594（仅演示）**；管理员发布后重新提问，再恢复 v1。其他区域的价格保持原样。并行候选为 **0.1390（仅演示）**。

## RAG 实验室演示（约 8–10 分钟）

以 **21v-admin** 进入“RAG 实验室”。六个 Tab 支持自由切换，也可按“下一阶段”推进；草稿自动保存，键盘方向键可切换 Tab。

1. **创建实验。** 选择 ACN、Playbook、全局默认或跨库联合范围。知识库从自己的生效方案复制配置；没有独立方案时继承全局默认。
2. **入库与索引。** 查看 JSON 的原始来源、业务上下文、可检索证据；或查看 Markdown 的标题与政策段落。调整 Chunk、重叠、中文分词、术语、Embedding 和独立入库理解模型，点击“准备候选索引”。“查看原文、diff 与版本”连接已有文档更新流程。
3. **召回 → 精排与上下文 → 生成。** 分别配置 BM25 / 向量候选数、业务过滤、Reranker、最终 Top K、上下文预算和生成模型 / Prompt。在召回页切换 Laoyang / Laojiu，观察权限过滤；生成页可比较 Prompt 与生效版本，并预览引用格式。
4. **先展示失败，再调优。** 初始默认方案缺少业务条件过滤、精排和强制引用。运行模拟评测，查看基线与候选的检索、生成、延迟、费用指标，以及失败用例。“载入推荐调优”可一次启用这些配置，再次运行后通过预置演示门槛。修改入库参数或知识版本时，需要重新准备候选索引。
5. **人工金标。** 查看示例问题、期望行为与证据定位；通过“人工添加金标”手工标注，也可选取反馈中心标记的项目知识候选。确认脱敏后生成金标新版本，旧评测失效。新增用例每次运行均需在“查看”中人工判定；Demo 不自动为自定义问题生成答案或打分。
6. **审核、发布与回退。** 全部门槛和人工用例通过后，在“审核与发布”提交，填写意见，确认发布或退回。回退恢复上一配置并创建新记录。可查看运行快照、导出 JSON 报告。跨库联合实验同时检查两个知识库，基线取各库生效配置，报告不单独发布为配置。

每次运行冻结知识版本、索引、配置、Prompt、授权和金标版本。任一输入变化后，旧结果不能用于新发布。入库策略变化要求重建候选索引；已有实验快照和发布记录保留。

**演示边界：** 分块、LLM 理解、检索 / 精排、模型生成及评测指标均为本地示意；指标来自预置规则，不是用例统计结果，也不是生产 benchmark。联合基线保守取各库较差的模拟指标。新方案发布仅改变实验室的配置记录，Ask AI 保持现有样例回答逻辑；知识文档在原有审核模块独立发布。真实系统需把候选知识、索引与 RAG 配置作为经过共同验收的发布包切换。

## 真实内容与模拟边界

| 内容 | 实现范围 |
| --- | --- |
| 原始资料 | 内置 MySQL JSON 与 Playbook Markdown 原始样例；对应当前 `sample-data/acn-payloads/zh-cn/pricing/mysql.json` 和 `sample-data/playbook/` 中的文档；保留 SHA-256，源文件不改写 |
| 定价读取 | 从真实 JSON 的区域 HTML 表格提取规格、价格和单位；月度估算按明确标注的 730 小时计算 |
| 预置修订 diff | 用真实 `git diff --no-index` 预生成，包括原始 JSON 中 HTML 字段的实际行变化；“可读对比”辅助阅读 |
| 临时上传 / 回退 diff | 浏览器本地文本对比，合并为一个变更区段；生产版本需要接入后端 Git 多区段差异与审计 |
| 生命周期 | 本地真实状态流转，待审版本不生效；冲突 / 失败阻止切换；成功发布更新版本清单；回退创建新版本 |
| Ask AI | 本地样例意图匹配与原文摘录，支持区域 / 规格问题和常见政策问题；上传资料按标题 / 分词匹配，不是真实 LLM 或向量检索 |
| 个人记忆 | 默认在后台按当前用户提取四类个人信息；跨会话保留，支持更正、暂停和删除；只演示隔离行为，真实安全依赖后端身份认证与授权 |
| 权限 | 界面与本地查询逻辑演示组授权、个人范围、撤销后的隐藏；静态资源含全部样例，不构成服务端安全隔离 |
| 冲突 | 展示同一文档的并行待审修订及人工取舍；尚未实现跨文档语义矛盾检测和自动合并 |
| RAG 实验室 | 六阶段配置、独立知识库方案、联合评测、人工金标、冻结快照、发布门槛、审核与回退；所有算法结果和性能数值均为模拟 |
| 管理 | 固定演示用户与组；模型连接、索引准备和费用都是明确标注的模拟数据 |
| 后续能力 | CMS 接入、真实身份认证与后端授权、真实 RAG、PDF / Office 解析、多组织服务尚未接入 |

资料中的政策日期来自用户提供的样例，并非对最新政策的外部核验。演示构造的流程与价格均有明确标识。

## 维护与验证

```sh
# 在仓库根目录运行，需要 Node.js；不安装任何 npm 包
node functional-demo/self-test.cjs
node --check functional-demo/app.js
node --check functional-demo/core.js

# 只有需要重新打包样例时才运行，需要 Python 3 和 Git
python3 functional-demo/prepare_data.py
```

自检覆盖源文件完整性、组权限、个人隔离、发布、索引失败、并行冲突、过期基线、回退、撤回、报价更新、中文上传文档匹配，记忆的用户隔离、更正、暂停、删除、序列化与知识权限边界，以及 RAG 的配置失效、金标判定、权限变化、索引重建、审核、发布与回退。

`index.html` 是入口；`styles.css` 为样式；`app.js` 为交互界面；`core.js` 为本地权限、版本与问答逻辑；`data.js` 为完整样例和预生成差异。整个文件夹可以复制到另一台电脑进行演示。
