# Hybrid Search Engine · 21v 知识工作台

面向企业内部的知识问答与管理平台。让员工在自己的权限范围内查询产品价格、操作手册和项目资料，获得有来源、可追溯的答案。

项目从 **21v-DEV 开发组内部试运行**开始，逐步扩展到公司其他部门，远期支持不同客户和组织独立使用。

## 当前状态

项目正在重启。仓库保留了早期 RAG 探索代码，真实后端尚未完成端到端验证。[functional-demo](functional-demo/) 是用于会议展示的静态交互 Demo，问答、权限和管理流程主要在浏览器本地演示，尚未接入真实模型与后端服务。

**下面列出的主要功能是当前建设目标，不代表已经全部实现。**

## 主要功能

- **Ask AI 知识问答**：聊天式提问、流式回答、会话记录和答案反馈。仅查询当前用户有权限访问、已经发布的知识，展示引用原文与版本。个人 memory 默认在后台生效，按用户隔离，支持管理和删除，不能扩大知识访问权限。

- **知识库与权限管理**：首期支持 AzureCNArchaeologist 的产品 pricing JSON 和 Markdown Playbook，后续接入 CMS，并扩展 PDF、Word、Excel、PPT。个人知识默认仅本人可见；项目知识库按用户组分别授予查询、阅读和上传权限，管理员不自动获得私人资料或 memory 的读取权限。

- **文档解析与入库**：程序解析结合 LLM 辅助理解，形成相互关联的原始来源、业务上下文和可检索证据。JSON 保留产品、区域、规格、价格、单位及适用条件；Markdown 围绕标题、完整步骤、注意事项和政策时间组织内容。入库模型可独立于聊天模型配置，提取结果需要校验并保留原文依据。

- **知识版本与发布**：保留原始资料，通过 `git diff` 追踪文档变更，支持修订审核、冲突处理、旧知识替换、撤回和回退。新内容先形成候选版本，校验与评测通过后人工确认发布。

- **RAG 实验室**：全局提供默认方案，每个知识库可以单独调优，跨知识库问答进行联合评测。覆盖切分与重叠、中文与术语处理、Embedding、全文检索／BM25、向量召回、结果融合、Rerank、各阶段 Top K，以及生成模型和 Prompt 版本；支持保存实验、对比基线和检查失败案例。

- **人工 Golden Dataset**：人工构建并复核金标，记录问题、测试身份、预期行为、原文证据和答案要求，覆盖价格、操作步骤、时效性、无答案和权限隔离等场景。金标独立于用户可检索知识管理，文档更新后复核受影响题目。

- **质量与性能评测**：分别评估入库、检索与生成质量，检查引用与权限边界，同时评估延迟、并发、稳定性和费用。候选版本达到产品规定的 benchmark 后，才进入人工发布审核。

- **管理后台与反馈闭环**：管理员管理用户、项目知识库、模型供应商、实验配置、用量与预算；普通用户上传资料、问答和反馈。反馈关联回答与知识版本，经人工核实、授权和必要的脱敏后，用于知识修订、回归评测与下一轮调优。

## 工作流程

资料上传／变更 → 解析与校验 → 候选知识版本 → 实验与评测 → 人工审核 → 发布 → 用户问答与反馈 → 人工归因 → 知识、金标和方案更新。

开发按模块逐步推进，优先用少量真实资料和人工金标跑通完整流程，再扩大知识覆盖和使用范围。

## 体验静态 Demo

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory functional-demo
```

打开 [本地 Demo](http://127.0.0.1:8765/)，可切换管理员 `21v-admin`，以及普通用户 `Laoyang`、`ZZQ`、`Laojiu`、`Daozi`，演示不同权限和知识范围。
